## F9 對照表（定版，照「偵測共用／處置共用」分開；2026-09-25）

每一條必備情境拆成兩層：**偵測**（閘門怎麼認出這個狀況）、**處置**（認出來之後做什麼）。處置共用、偵測各自獨立時不必改設計，但偵測那一層
每一種要有只紅它的突變；偵測共用才是真的只有一道防線，要改設計或照實寫明。所有突變都 commit 在暫存複本裡、印出 HEAD 裡的雜湊，
**正反兩種順序各跑一次、紅的一樣**（沒改壞的同一份兩種順序 135 項逐一相同）。

| 必備情境 | 偵測（靠哪一段認出來） | 處置 | 只紅它的突變 |
|---|---|---|---|
| ① 改被守的檔、commit、沒跑驗法就推 → 擋在第零關、點名驗法（P3） | F8 那一關**逐支**比「登記的值 vs HEAD 裡的值」 | 停（回 6）、✗ 行點名 `npm run f8verify`；處置跟 P6、Q7 共用 | 偵測：只比第一支 → **只紅 P3**。處置：✗ 行不點名驗法 → 只紅 P3 |
| ② 跑過驗法之後同一個改動 → 推得出去（P2） | **同一道逐支比對**（跟 ① 共用），這次是「全部相同」 | 放行、印「登記相符」 | 處置：相符也擋 → **只紅 P2**。偵測：比對永遠判不相同 → P2、**P3 一起紅**（見下面「照實寫明」） |
| ③ 驗法沒全過 → 登記被刪 → 推不出去（S3） | `f8verify` 認出自己跑不下去：先查「被守的檔在不在 HEAD、工作區＝HEAD」，查不到再由「開不了暫存複本」接住（兩道偵測互為備援） | 刪登記，兩道：開始前先刪、中途停下時刪（處置跟 ④ 共用 `give()`） | 處置：兩道刪登記都拿掉 → **只紅 S3**；只拿一道 → 全過（等價突變）。偵測只拿一道也是等價（另一道接住） |
| ④ 工作區有改動時跑驗法 → 不寫新登記（S4） | `verified-reg` 的「工作區跟 HEAD 不一樣」那一條（跟 ③ 用同一個函式、**不同分支**） | 不跑、刪登記（跟 ③ 共用） | 偵測：那一條拿掉 → 六條裡**只紅 S4**（另紅 V2，是同一條偵測在函式層的測試） |
| ⑤ 沒動到被守的檔、也沒有登記 → 照常推得出去（P4） | 共同一環 A（列出動到的檔）判「沒動到」 | 不看登記、放行 | 處置：不管有沒有動到都看 → **只紅 P4**（起點改成「登記有效」之後才做得到只紅它） |
| ⑥ 前一個 commit 動到、最後一個乾淨 → 仍要擋（P5） | `git log --name-only 範圍`——**範圍裡每一個 commit** | 落到共同一環 B（沒有登記就停） | 偵測：只看最後一個 commit → **只紅 P5** |
| 共同一環 A：列出這次動到的檔 | ①②③⑥ 靠它認出「動到了」、⑤ 靠它認出「沒動到」 | — | 比對永遠對不上 → P1、P2、P3、P5、P6、P7、S3、Q7 一起紅 |
| 共同一環 B：沒有登記檔就停 | ③⑥ 最後一步、P1、P7 | 停（回 6） | 拿掉 → P1、P5、P7、S3 紅，回 1 不是 6（背後有隱式的擋：接著讀登記檔那一行失敗、`set -e` 停下；「讓它放行」的突變沒做，列在該補未補） |

**照實寫明（偵測共用的那一處）**：① 與 ② 用的是**同一道**逐支比對——它不是兩道防線共用一道，而是**同一道檢查的兩個結果**（抓到不同就擋、
全部相同就放）。所以「比對本身壞成永遠不同」會同時讓 ② 誤擋、① 點名點錯支（P2、P3 一起紅）。不改設計的理由：要驗「會擋」和「會放」，
只能對同一個比較器；兩邊各自仍有只紅自己的突變（① 偵測層的「只比第一支」、② 處置層的「相符也擋」）。
