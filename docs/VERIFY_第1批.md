# 待驗清單：行程頁第 1 批＋第 1 輪（2026-10-27 起草；等 Dispatch 排瀏覽器時段一次驗完）

**硬要求（Dispatch 2026-10-27）：判準寫成「使用者看得到什麼」，不是「某個物件存在」。**
每一項都先問一次：**這一項紅的時候，是因為使用者看不到，還是只因為某個節點不在？** 只回答得了後者的，不算驗過。

做法：自動的那幾條用 `itinviewtest` 的 `seen()`——把元素像使用者一樣捲到畫面中間，確認
① 在視窗裡、有大小；② 正中央那一點打到的是它自己（沒被黏住的日期列、標題列、底部分頁蓋住）；
③ 沒被 `visibility`／`display`／`opacity` 藏起來（往上一路乘 opacity）；④ 字對它實際的底 ≥ 4.5。
**靜態檢查（palettetest）看不到 opacity、看不到疊在什麼上面**，所以「淡化」「蓋住」只能在瀏覽器裡驗。
截圖那幾條是機器判不了的（裝飾、擠不擠），由人看截圖判；寫明要截哪一張、看哪裡。

格式：編號｜要看什麼｜怎麼算通過｜怎麼驗（自動＝哪支哪條、截圖＝哪張）｜紅的時候代表什麼
